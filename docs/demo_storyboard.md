# 오디 (Odee) 숏폼 콘티 (세로 9:16, 55초)

**규격:** 30초~1분 세로 숏폼(릴스/쇼츠), 게시 링크는 접수 양식 8번(이메일 제출)
**구성 (1080×1920):** 상단 자막 띠 / 가운데 IVI 화면(2560×1440 → 1080×608) / 하단 폰(컴패니언)
**준비:** `docker compose up -d` · `pnpm dev:server`·`dev:simulator`·`dev:companion` + Pleos 에뮬레이터. 시뮬레이터 프리셋 `0`으로 리셋, 오디는 우측 엣지 스와이프로 **드로워에 열어 지도 옆에 둔다**(앱이 직접 열 수 없음)

| 시간 | 조작 | 화면 | 자막 |
| :--- | :--- | :--- | :--- |
| 0–4s | — | 순정 내비 지도 + 드로워 오디 1줄 요약("2호차 · 3분 뒤 · 정상") | "일행 차, 어디 갔지?" |
| 4–16s | 고속 `92km/h` → 프리셋 `1` | **지도는 그대로**, 알림 배너 + TTS "2호차가 판교 분기점을 지나쳐…" → 운전자 "연결해줘" | "고속에선 화면 대신 음성으로" |
| 16–22s | (통화 연결) | 드로워 통화 카드 · `30% DUCKED` · 앰비언트 Green | "음악·안내음은 작게, 통화는 선명하게" |
| 22–26s | 발화 "오디 마이크 꺼줘" → "통화 끊어줘" | 마이크 꺼짐 표시 → 통화 종료 | "손은 핸들에" |
| 26–36s | 정차 `P단` → 프리셋 `2` | 오디가 앞으로: "2호차 배터리 16% 충전소 진입", [함께 경유] → 내비 경유지 반영 → 내비 복귀 | "이탈한 이유까지 안다" |
| 36–44s | 주행 `42km/h`, 발화 "오디 일행 어디쯤이야?" | 지도 유지 · Gleo 음성 "2호차 EV9 32km 앞, 14:45 도착." | "궁금하면 Gleo에게" |
| 44–52s | 프리셋 `4` (하단 폰 강조) | 폰에서 우회 경로 추천 → 차에 "8분 단축" 알림 · Cyan → 수락 → 폰과 통화 | "기다리는 가족이 길 안내 · 앱 설치 없이" |
| 52–55s | 프리셋 `5` | 세션 파기 → 로고 | "도착하면 기록 삭제 · 오디" |

> 고속 `92km/h` 버튼은 제동 포함이라 급제동 배너가 함께 뜰 수 있음. 4–16s 컷이 지저분하면 IVI 쪽 속도 선택으로 대체.

## 녹화·합성 (한 번에 한 흐름)
**배치:** 컨트롤 타워·컴패니언(폭 ~490px)·에뮬레이터 창 3개를 겹치지 않게 놓는다. 숏폼은 에뮬레이터·컴패니언만 잘라 쓰고, 풀 시연 영상은 3개 모두 사용.
**오디오:** ⇧⌘5·QuickTime은 시스템 소리를 못 받으므로 BlackHole 사용. 오디오 MIDI 설정에서 다중 출력 기기(MacBook 스피커 + BlackHole 16ch, 스피커 쪽 '동기화' 체크) → 사운드 출력을 그 기기로 → 에뮬레이터 재시작(시작 시 출력 장치를 잡음) → ⇧⌘5 옵션 마이크 = BlackHole 16ch. 운전자 발화는 담기지 않으므로 자막으로 표시. Gleo 발화를 위해 에뮬레이터 확장 설정 → Microphone → "Virtual microphone uses host audio input" 켜기.
**녹화:** ⇧⌘5 → 전체 화면 기록. 프리셋 `0` 리셋 후 표의 흐름대로 끊지 않고 진행(NG 나면 `0`부터 다시). 원본에는 바탕화면·터미널이 담기니 공유 금지.
**합성:** 녹화 파일에서 두 창 영역을 잘라 세로로 쌓는다. 좌표는 녹화 영상 한 프레임에서 확인(`ffmpeg -ss 5 -i rec.mov -frames:v 1 frame.png`).
```sh
# IVI=폭:높이:x:y, PHONE=폭:높이:x:y (녹화 영상 픽셀 기준, ffmpeg crop 순서)
IVI=2560:1440:0:0 PHONE=860:1860:2600:0
ffmpeg -i out/rec.mov -filter_complex \
 "[0:v]split[a][b];[a]crop=${IVI},scale=1080:608:force_original_aspect_ratio=decrease,pad=1080:908:(ow-iw)/2:300+(608-ih)/2:black[top];\
  [b]crop=${PHONE},scale=1080:1012:force_original_aspect_ratio=decrease,pad=1080:1012:(ow-iw)/2:0:black[bot];[top][bot]vstack,fps=30[v]" \
 -map "[v]" -map '0:a?' -c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac out/odee_short.mp4
```
- 위 300px 띠·하단 여백에 CapCut으로 자막·BGM. 길면 CapCut에서 구간 컷(흐름은 유지)
- 폰 장면이 없는 구간(A-1·A-2)은 하단에 컴패니언 지도가 함께 움직여 "모두가 같은 세션"을 보여 줌
