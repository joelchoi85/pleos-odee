# 공모전 접수 양식 (11/15 마감)

> 공유 링크·첨부자료에 개인정보·계정정보·개발자 실명이 노출되지 않도록 확인할 것.
> 상세 기술요건은 공식 안내를 따르며, 필요 시 별지 추가 가능.

1. **앱 한 줄 소개** — 앱을 한 문장으로 소개
2. **기획 배경** — 주목한 고객 니즈·불편한 순간, 해결이 필요한 이유
3. **앱 주요 기능 및 차량 특화 요소** — 핵심 기능, 해결하는 문제, 차량에서의 새로운 경험
4. **주요 사용 시나리오** — 누가, 어떤 상황에서, 어떻게 쓰는지 이용 흐름
5. **개발 계획** — Pleos Connect 구현 범위와 SDK/API 사용 계획
6. **기대효과 및 발전 가능성** — 사용자 가치, 확장 계획 (타깃 고객 분석, 예상 MAU, Retention Rate, 향후 서비스 확대 계획 등)
7. **참고자료** (선택·가산점) — 화면 시안, 시연 영상, GitHub 저장소 등 파일 또는 링크
8. **숏폼 링크** (선택·가산점 없음, 별도 특별상 50만원) — 게시한 세로 영상 링크를 이메일로 제출
